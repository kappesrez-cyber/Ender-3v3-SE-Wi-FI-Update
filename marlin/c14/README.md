# C14 (STM32F401RET6)

Свободного аппаратного UART на этой ревизии нет — подробности в [docs/uart-analysis.md](../../docs/uart-analysis.md).

Рекомендуемый вариант — подключить ESP к USART1 (PA9/PA10) вместо USB/CH340. Прошивку Marlin для этого менять не нужно: можно оставить стоковую. Нужна только аппаратная развязка CH340 от линии RX (PA10) — решим по фото платы.

Если понадобится своя сборка под C14 (например, ради скорости порта), основа — форк сообщества [navaismo/Ender-3V3-SE](https://github.com/navaismo/Ender-3V3-SE), ветка `SMT32F401`: официальных исходников Creality под C14 нет.
