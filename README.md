# Wi-Fi печать на Creality Ender 3 V3 SE

Печать по Wi-Fi прямо из Orca Slicer (кнопка Print — принтер начинает печать) без компьютера или Raspberry Pi у принтера. В перспективе — несколько принтеров и общая панель управления.

```
Orca Slicer ──Wi-Fi──► ESP32 (ESP3D 2.1) ──UART──► плата принтера (Marlin Creality + второй порт)
Панель (браузер) ──Wi-Fi──┘                                    └─► файл пишется на microSD принтера
```

- **ESP32-WROOM-32U** с внешней антенной и прошивкой **ESP3D 2.1.x** — Wi-Fi мост к UART принтера.
- **Marlin** из открытых исходников Creality, изменена только конфигурация: включён второй последовательный порт для ESP.
- **Orca Slicer ≥ 2.1**, тип хоста ESP3D: загружает файл на SD принтера и запускает печать.
- **Панель 309_base** `panel/index.html` — все принтеры на одном экране.

Прошивку с нуля не пишем, thermal runaway и поддержку родного экрана не трогаем.

## Главные выводы

1. **C13 (GD32F303):** свободен USART3 на PB10 (TX) / PB11 (RX) — ножки 29/30 МК. В прошивке они не используются (DIAG-пины TMC работают только при sensorless homing, а он выключен). Нужно проверить на плате, куда эти ножки выведены и не висит ли на них DIAG драйвера.
2. **C14 (STM32F401):** у F401 нет USART3, а USART6 занят (HX711, SD_DETECT, энкодер). Рекомендуемый вариант — подключить ESP к USART1 вместо USB (CH340), прошивку не менять, но развязать CH340 от линии RX.
3. **Orca + ESP3D работают только с ESP3D 2.1.x.** Orca загружает файл через `/upload_serial`, а этот обработчик есть только в ветке 2.1.x (в 3.0/3.1 его нет). Файл пишется на **SD принтера** командами `M28`/`M29`, так что модуль microSD для ESP **не нужен**.
4. Загрузка идёт со скоростью UART: на 115200 бод большие файлы грузятся долго. После запуска поднимем скорость до 250000–500000.

## Структура репозитория

```
marlin/c13/*.patch        правки Marlin для платы C13 (второй порт + фикс сборки с ним)
marlin/shim/              заголовки-переходники для сборки исходников Creality на Linux
marlin/c14/               C14 — после выбора варианта подключения
esp3d/*.patch             правки ESP3D 2.1.x: UART2 GPIO16/17, CORS для панели
panel/index.html          панель управления всеми принтерами
scripts/build-marlin.sh   скачать исходники Creality, применить патчи, собрать .bin
scripts/build-esp3d.sh    скачать ESP3D, применить патчи, собрать образ для ESP32
docs/                     анализ и инструкции
.github/workflows/        автоматическая сборка прошивок
```

Исходники Creality и ESP3D в репозиторий не копируются — скрипты скачивают их на зафиксированных коммитах и накладывают наши патчи. Готовые прошивки — в артефактах GitHub Actions (вкладка **Actions** → последний запуск **Build firmware** → Artifacts).

## Безопасность

- Прошивка от одной ревизии на другой может «окирпичить» плату — сначала убедиться в ревизии.
- Первые печати после перепрошивки — под присмотром.
- Работы с платой — только при отключённом от сети принтере.
