# 309_base — единая панель для всех принтеров

Одна веб-страница [`panel/index.html`](../panel/index.html), которая показывает все принтеры с модулями ESP3D на одном экране и управляет ими. Отдельный сервер не нужен: страница — обычный HTML-файл, который хранится прямо в памяти одного из модулей ESP32.

## Что умеет

- Карточка на каждый принтер: на связи / печатает / нет связи, температура сопла и стола (текущая и заданная), процент печати.
- Пауза (`M25`), продолжить (`M24`), стоп (`M524`, подтверждение вторым нажатием).
- Список файлов на SD принтера (`M20`) и запуск печати выбранного (`M23` + `M24`).
- Загрузка G-code с телефона/ПК прямо на SD принтера и автоматический старт — тем же способом, что и Orca (`/upload_serial`, имя 8.3).
- Консоль для любых G-code команд.
- Список принтеров (название + IP) хранится в браузере; добавляется кнопкой «Добавить принтер».

Статус обновляется раз в 5 секунд запросами `M105` и `M27`. Запросы к одному модулю идут строго по очереди, во время загрузки файла опрос этого принтера приостанавливается.

## Как это работает и почему нужен патч CORS

Страница обращается к HTTP API каждого модуля (`/command?plain=<G-code>` и `/upload_serial`). Браузер разрешает странице с одного адреса читать ответы другого адреса только если тот отвечает заголовком `Access-Control-Allow-Origin` (CORS). Стоковый ESP3D 2.1.x этот заголовок не отправляет (проверено по исходникам `syncwebserver.cpp`), поэтому панель видела бы только свой «родной» модуль.

Мы собираем ESP3D сами, так что добавили заголовок патчем [`esp3d/0002-cors-for-panel.patch`](../esp3d/0002-cors-for-panel.patch) — в ответы `/command`, `/command_silent`, `/upload_serial` и списка файлов. Запросы панели «простые» по правилам CORS (GET и POST multipart без своих заголовков), так что preflight-запросы `OPTIONS` не нужны.

Ограничения браузера, из-за которых панель надо открывать **по http из локальной сети**:

- со страницы по https (например, GitHub Pages) браузер не пустит запросы на `http://192.168.x.x` (mixed content);
- Chrome дополнительно блокирует запросы из интернета к адресам локальной сети (Private Network Access).

Поэтому лучший вариант — положить панель на один из модулей.

## Дизайн

Чёрная минималистичная тема из прототипа 309_base: стеклянные карточки (Liquid glass, `backdrop-filter`), шрифт Murs Gothic для заголовков, цифр и кнопок, без градиентов. Шрифт встроен прямо в `index.html`, поэтому панель выглядит одинаково и в сети без интернета. Inter и JetBrains Mono подгружаются из Google Fonts, если интернет есть, иначе берутся системные шрифты.

## Проверка без железа

[`tools/esp3d_emulator.py`](../tools/esp3d_emulator.py) изображает несколько модулей ESP3D 2.1 с Marlin за ними: температуры, SD-карта, печать с прогрессом, пауза, стоп, загрузка через `/upload_serial`. Как и настоящий ESP3D, он не отвечает на предварительные запросы `OPTIONS`, так что тест ловит ошибки CORS.

```bash
python3 tools/esp3d_emulator.py --ports 8081 8082 8083
# панель: http://127.0.0.1:8081/panel.html, принтеры: 127.0.0.1:8081, :8082, :8083
node tools/panel_test.js   # автотест в браузере (нужен playwright)
```

Автотест (23 проверки) запускается в GitHub Actions на каждый пуш. Эмулятором можно проверить и Orca: хост `127.0.0.1:8081`, тип ESP3D.

## Установка

1. Открыть веб-интерфейс любого модуля ESP3D (например, `http://192.168.1.50`).
2. Раздел файлов ESP (SPIFFS / ESP Files) → загрузить `panel/index.html`, переименовав его в `panel.html`.
3. Открыть `http://192.168.1.50/panel.html` с телефона или ПК. Добавить в закладки / на главный экран телефона.
4. Нажать «Добавить принтер» для каждого принтера: название и IP его модуля.

Запасной вариант без загрузки на ESP — открыть `index.html` как локальный файл на ПК (двойной клик). Это обычно работает, но в некоторых браузерах локальные файлы ограничены сильнее.

## Безопасность

В ESP3D по умолчанию нет авторизации на `/command`: любой, кто подключён к домашней Wi-Fi, может управлять принтером. Для дома это обычно приемлемо. Не пробрасывать порты модулей в интернет. Для удалённого доступа позже можно рассмотреть VPN до домашней сети (например, WireGuard на роутере).

## Что проверить на живом железе

- Корректно ли родной экран Creality отображает печать, запущенную по `M23`/`M24` с хоста.
- Стабильность опроса во время печати (`M105`/`M27` раз в 5 с не должны вызывать паузы).
- Поведение `M524` (стоп) — после него Creality выполняет `G28XY`, отводит стол и выключает моторы (`EVENT_GCODE_SD_ABORT`).
