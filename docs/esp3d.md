# ESP3D на ESP32: сборка, прошивка, настройка

## Почему ESP3D 2.1.x, а не 3.0

Orca Slicer (тип хоста **ESP3D**, файл `src/slic3r/Utils/ESP3D.cpp`) работает так:

1. `GET /command?plain=M105` — проверка связи;
2. `POST /upload_serial` — загрузка G-code, ESP3D передаёт файл в Marlin командами `M28 <файл>` … `M29` прямо **на microSD принтера**;
3. `M23 <файл>` и `M24` — выбор файла и старт печати.

Обработчик `/upload_serial` есть только в ветке **ESP3D 2.1.x** (`esp3d/webinterface.cpp`). В ветках 3.0 и 3.1 его нет — Orca загрузить файл не сможет. Поэтому берём 2.1.x (коммит `80d5ed1`, версия 2.1.4).

Следствия:

- файл печатается **с SD-карты принтера** — никаких микропауз от потоковой передачи по UART;
- отдельный **модуль microSD для ESP не нужен** (можно не покупать);
- имена файлов Orca сама сокращает до формата 8.3;
- загрузка идёт со скоростью UART: на 115200 бод — порядка нескольких КБ/с, т. е. файл 5 МБ грузится десятки минут. После того как всё заработает, поднимем скорость обоих концов до 250000 или 500000 (одна строка в Marlin и настройка в ESP3D).

## Что изменено в ESP3D

Патч [`esp3d/0001-uart2-gpio16-17.patch`](../esp3d/0001-uart2-gpio16-17.patch), файл `esp3d/config.h`:

| Параметр | Было | Стало |
|---|---|---|
| UART к принтеру | `USE_SERIAL_0` | `USE_SERIAL_2` |
| RX / TX | по умолчанию | GPIO16 / GPIO17 |
| Имя хоста | `MYESP` | `ender3v3se` |

Скорость по умолчанию в ESP3D 2.1.x уже 115200.

## Сборка

Автоматически — GitHub Actions (workflow **Build firmware**) на каждый пуш, файлы в артефакте `esp3d-esp32`. Локально:

```bash
pip install platformio esptool
scripts/build-esp3d.sh
```

Результат:

- `out/esp3d-esp32-merged.bin` — полный образ для первой прошивки с адреса `0x0`;
- `out/esp3d-esp32-app.bin` — для последующих обновлений через веб-интерфейс ESP3D.

## Первая прошивка ESP32 (с Windows, без установки программ)

1. Подключить ESP32 к ПК кабелем micro-USB с данными. Если порт не появился — поставить драйвер CP210x или CH340 (по чипу на DevKitC).
2. Открыть в Chrome/Edge https://espressif.github.io/esptool-js/ → Connect → выбрать порт (если не подключается — держать кнопку BOOT при нажатии Connect).
3. Flash Address `0x0`, файл `esp3d-esp32-merged.bin` → Program.
4. Нажать EN (reset).

Альтернатива — `esptool.py --chip esp32 write_flash 0x0 esp3d-esp32-merged.bin`.

## Первая настройка

1. ESP поднимет точку доступа **ESP3D**, пароль **12345678**. Подключиться и открыть http://192.168.0.1.
2. При первом входе веб-интерфейс предложит скачать/установить интерфейс (index.html.gz) — согласиться.
3. Логин администратора по умолчанию `admin` / `admin` — **сменить**.
4. Настройки ESP3D:
   - Target firmware: **Marlin**;
   - Baud rate: **115200** (должен совпадать с `BAUDRATE_2` в Marlin);
   - Wi-Fi mode: **Station**, указать SSID и пароль домашней сети;
   - Hostname: для нескольких принтеров — разные имена (`ender3v3se-1`, `ender3v3se-2`…).
5. Перезагрузить ESP. В роутере закрепить за ним IP (DHCP-резервация по MAC) — этот IP потом вводим в Orca.
6. Проверка: в терминале веб-интерфейса отправить `M115` — должен прийти ответ Marlin.
