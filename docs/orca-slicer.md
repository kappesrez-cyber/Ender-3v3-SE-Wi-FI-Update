# Настройка Orca Slicer для печати по Wi-Fi

Нужна Orca Slicer **2.1.0 или новее** (в ней появился тип хоста ESP3D).

## Подключение принтера

Профиль принтера — системный **Creality Ender-3 V3 SE 0.4 nozzle** (G-code flavor `marlin2`). Физический принтер привязывается к нему:

1. Вкладка **Устройство / Device** или значок Wi-Fi рядом с выбором принтера → **Физический принтер / Physical printer**.
2. **Тип хоста (Host Type): ESP3D**.
3. **Адрес (Hostname, IP or URL):** IP модуля, например `192.168.1.50` (без `http://`). Можно `ender3v3se.local`, но IP надёжнее.
4. **Test** — Orca отправит `M105`. Должно появиться «Connection to ESP3D is working correctly».
5. OK.

Можно потренироваться без железа: запусти эмулятор (`python3 tools/esp3d_emulator.py`, см. [panel.md](panel.md#проверка-без-железа)) и укажи хост `127.0.0.1:8081`. Test пройдёт, Print «загрузит» файл и «запустит» печать, а её прогресс будет виден в панели 309_base.

Готовый файл физического принтера для импорта не делаю: Orca хранит такие настройки в служебной папке в своём JSON-формате, который меняется от версии к версии. Настройка вручную занимает меньше минуты и надёжнее.

## Печать

1. Нарезать модель.
2. **Print** (Печать) → Orca загружает файл на SD-карту принтера и отправляет `M23` + `M24` — печать стартует.
3. **Send** (Отправить) — только загрузить файл на SD без старта.

Особенности:

- Имя файла Orca сама сокращает до формата 8.3 (ограничение ESP3D/Marlin) — это нормально.
- Пока файл грузится, принтер занят приёмом. На 115200 бод большие файлы идут долго; позже поднимем скорость порта.
- Не закрывать Orca до окончания загрузки — `M24` отправляется только после неё.

## G-code в профиле

Стартовый и конечный G-code — стандартный профиль Creality Ender-3 V3 SE из Orca. Ничего особенного для Wi-Fi не нужно.

## Проблемы

| Симптом | Что проверить |
|---|---|
| Test не проходит | IP модуля, тот ли Wi-Fi у ПК, открывается ли веб-интерфейс ESP3D в браузере |
| Test проходит, загрузка падает | Отвечает ли Marlin на `M115` из веб-терминала ESP3D; вставлена ли SD-карта в принтер; скорость ESP3D = `BAUDRATE_2` |
| Файл загрузился, печать не стартовала | Имя файла на SD (`M20` в терминале), повторить `M23 имя` и `M24` вручную |
