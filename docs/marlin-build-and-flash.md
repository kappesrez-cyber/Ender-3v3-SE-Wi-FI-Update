# Marlin: сборка и прошивка принтера

Свою прошивку не пишем — берём исходники Creality и меняем только конфигурацию.

## Что меняется (C13)

Патч [`marlin/c13/0001-esp3d-on-usart3.patch`](../marlin/c13/0001-esp3d-on-usart3.patch), только `Marlin/Configuration.h`:

- `#define SERIAL_PORT_2 3` — второй порт хоста на USART3 (PB10/PB11);
- `#define BAUDRATE_2 115200`;
- `STRING_CONFIG_H_AUTHOR "Creality + ESP3D Wi-Fi"` — метка в ответе `M115`, чтобы было видно, что прошита наша сборка.

Не трогаем: экран DWIN, USB-порт (`SERIAL_PORT 1`), защиту thermal runaway, кинематику, датчики.

## Сборка

Автоматически — GitHub Actions (**Build firmware**), артефакт `marlin-c13`, файл вида `E3V3SE_C13_ESP3D_20261112-2130.bin`. В имени — дата и время сборки, поэтому оно всегда уникальное.

Локально (Linux/macOS/WSL):

```bash
pip install platformio
scripts/build-marlin.sh c13
```

Скрипт скачивает исходники Creality на зафиксированном коммите, применяет патчи из `marlin/c13/` и собирает env `STM32F103RET6_creality`.

## Прошивка через microSD

1. **Убедиться, что ревизия платы — C13.** Прошивка от C13 на C14 (и наоборот) может сделать плату «кирпичом».
2. Сохранить на ПК текущую стоковую прошивку под свою ревизию с сайта Creality — для отката.
3. Карта microSD: FAT32, размер кластера 4096. Лучше отдельная карта, на ней только один `.bin`.
4. Положить `.bin` в корень карты. Имя должно отличаться от ранее прошитого (у нас имя уникально).
5. Выключить принтер, вставить карту, включить. Обновление идёт ~10–30 с, экран может быть тёмным — **не выключать**.
6. Меню Info: проверить версию. Через USB или USB-TTL отправить `M115` — в ответе должно быть `Creality + ESP3D Wi-Fi`.
7. Сбросить EEPROM при необходимости (`M502`, `M500`) и заново выставить Z-offset.

## Проверка после прошивки (под присмотром)

- [ ] Экран работает, меню открывается, энкодер крутится.
- [ ] Хоуминг всех осей.
- [ ] Нагрев стола и хотэнда до рабочих температур.
- [ ] Проверка thermal runaway не нужна «на живую», но не оставлять принтер без присмотра в первых печатях.
- [ ] Автовыравнивание (CR Touch) и авто Z-offset.
- [ ] Печать тестового файла с SD.

## Если что-то пошло не так

- Прошить стоковый `.bin` с сайта Creality (с новым уникальным именем).
- Если плата не стартует вообще — восстановление через ST-Link V2 по SWD (SWDIO/SWCLK/GND/3.3V на плате); инструкцию подготовлю по фото платы.
