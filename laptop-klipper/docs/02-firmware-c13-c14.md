# 2. Прошивка платы принтера Klipper'ом (C13 / C14)

Klipper состоит из двух частей: «мозг» (`klippy`) работает на ноутбуке, а на
плате принтера стоит маленькая прошивка, которая только исполняет команды.
Её и надо прошить вместо Marlin. Делается это так же, как обычное обновление:
файл `.bin` на microSD.

## 0. Перед началом

1. **Ревизия платы.** Сними нижнюю крышку (принтер выключен из розетки!) и найди
   надпись `CR4NS200320C13` или `CR4NS200320C14`. Сфотографируй плату целиком
   и крупно — главный чип (квадратный, 64 ноги).
2. **Сохрани стоковую прошивку** своей ревизии с сайта Creality
   (<https://www.creality.com/pages/download-ender-3-v3-se>) — это путь назад на Marlin.
3. **Прошивка экрана — 1.0.6.** Посмотри в меню принтера (Info). Если другая —
   сначала прошей экран 1.0.6 по инструкции Creality, иначе картинки на экране
   под Klipper «поедут». Новая 1.1.0 с jpcurti не проверена.
4. microSD до 32 ГБ, **FAT32, размер кластера 4096**.

## 1. Какой вариант сборки

> **Наш принтер (фото платы от 13.11.2026):** `CR4NS200320C13`, чип
> **GigaDevice GD32F303RET6**, кварц **8,000 МГц**. Это ровно та плата, под
> которую сделаны сборка и `printer.cfg`: собирать `--board c13`.
> На плате рядом с МК есть незапаянная 5-контактная гребёнка **J2** — по
> расположению похожа на SWD для ST-Link (назначение выводов прозвонить
> мультиметром до подключения).

| Плата | Чип | Сборка Klipper | Статус |
|---|---|---|---|
| C13 | GD32F303 | STM32F103, загрузчик 28KiB, USART1 PA10/PA9, мост экрана USART2 | проверено сообществом (0xD34D, jpcurti) |
| C14 | GD32F303 / STM32F103 | то же самое | должно работать — та же схема; проверь чип |
| C14 | STM32F401 | — | **не собираем**: нет проверенной конфигурации, пришли фото платы |

Почему GD32F303 собирается как STM32F103: это совместимый клон, загрузчик
Creality стоит с адреса 0x7000 (28 КиБ) — так прошивают все, кто ставил Klipper на V3 SE.

## 2. Сборка (на ноутбуке, после установки Klipper через KIAUH)

```sh
cd ~/e3se/laptop-klipper/scripts
bash 03-build-firmware.sh --board c13
# C14:  bash 03-build-firmware.sh --board c14 --chip gd32f303
# сразу на карту: добавь --sd /media/max/XXXX-XXXX
```

Скрипт сам выставляет параметры, которые в инструкции jpcurti выбираются в
`make menuconfig`:

```
Micro-controller Architecture:  STMicroelectronics STM32
Processor model:                STM32F103
Bootloader offset:              28KiB bootloader
Communication interface:        Serial (on USART1 PA10/PA9)
Baud rate:                      115200
[*] Enable extra low-level configuration options
[*] Enable serial bridge   ->  [*] USART2
```

и кладёт файл в `~/firmware/kDDHHMM.bin`. Скопировать его на компьютер с
кард-ридером: `scp max@klipper.local:~/firmware/k*.bin .`

Можно не собирать, а взять готовый `.bin` из
[релизов jpcurti](https://github.com/jpcurti/ender3-v3-se-klipper-with-display/releases)
— но тогда версия прошивки должна совпадать с версией Klipper на ноутбуке
(иначе Klipper скажет «MCU Protocol error»). Своя сборка из того же `~/klipper` надёжнее.

## 3. Прошивка

1. На карте — только один `.bin` (имя **отличается** от прошлого прошитого файла).
2. Принтер выключен → вставить карту → включить → ждать 1–2 минуты.
3. Признак успеха: меню Marlin больше не появляется (экран на заставке или пустой
   до запуска Klipper на ноутбуке). Если снова Marlin — переименуй файл
   (скрипт при повторной сборке даст новое имя) и повтори.
4. Карту вынуть. Подключить принтер USB-кабелем (Type-C) к ноутбуку/хабу.

Если плата не отвечает совсем — восстановление через ST-Link (SWD) стоковой прошивкой.

## 4. Конфиг

```sh
bash find-printers.sh
bash 04-install-config.sh --serial /dev/serial/by-path/<путь>                  # один принтер
bash 04-install-config.sh --instance ender1 --serial /dev/serial/by-path/<путь>   # несколько
```

## Первый запуск

Делай под присмотром, рука рядом с выключателем. Команды — в консоли Mainsail.

1. `STATUS` / Mainsail показывает Ready, на экране принтера — меню Klipper.
2. **Температуры:** обе показывают комнатную (≈20–25 °C). Если 0 или -14 — не тот пин датчика.
3. **Концевики:** `QUERY_ENDSTOPS` → все `open`. Нажми рукой концевик X → `TRIGGERED`. Так же Y.
4. **Направления (без G28!):** `SET_KINEMATIC_POSITION X=100 Y=100 Z=10`, затем
   `G91` и `G1 X10 F1000` — голова должна уехать **вправо**; `G1 Y10` — стол едет
   **вперёд, к тебе** (сопло смещается к задней части стола); `G1 Z5` — голова **вверх**. Если не так —
   добавь/убери `!` у `dir_pin` этой оси. `G90` в конце.
5. **Датчик CR Touch:** `BLTOUCH_DEBUG COMMAND=pin_down` / `pin_up`, `QUERY_PROBE`.
6. `G28` — домой (держи руку на выключателе для первого раза).
7. **Нагреватели:** `PID_CALIBRATE HEATER=extruder TARGET=210`, затем
   `PID_CALIBRATE HEATER=heater_bed TARGET=60`, потом `SAVE_CONFIG`.
   Защита (`verify_heater`) включена по умолчанию — не отключай.
8. **Z-offset:** `CALIBRATE_Z_OFFSET` (тензодатчик, `PRTOUCH_PROBE_ZOFFSET`) или
   вручную `PROBE_CALIBRATE` + «бумажка» → `ACCEPT` → `SAVE_CONFIG`.
9. **Сетка стола:** `CALIBRATE_BED_MESH` (сохранит профиль `default`).
10. **Экструдер:** отметь 120 мм прутка, `LOAD_FILAMENT`, `G91`, `G1 E100 F100` при
    горячем сопле, измерь остаток. Новый `rotation_distance = 7.44 × фактически/100`.
11. Позже: `pressure_advance` (TUNING_TOWER), input shaping (нужен акселерометр ADXL345).

### Особенности C14

Если на C14 тот же GD32F303/STM32F103, пины, скорее всего, те же (ревизия
отличается обвязкой). Именно для этого шаги 2–5 выше: всё, что «не так», видно
до первого настоящего движения. Ошибки, которые точно нельзя пропускать:
неверная температура, концевик не срабатывает, ось едет не туда.
