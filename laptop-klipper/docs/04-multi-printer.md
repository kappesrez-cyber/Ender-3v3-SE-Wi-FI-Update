# 4. Несколько принтеров на одном ноутбуке

## Схема

```
                      ┌──────────────── Ноутбук ────────────────┐
Orca / браузер ──LAN──┤ nginx :80 → Mainsail (один интерфейс)    │
                      │                                          │
                      │ moonraker-ender1 :7125 ↔ klipper-ender1 ─┼─USB─┐
                      │ moonraker-ender2 :7126 ↔ klipper-ender2 ─┼─USB─┤  USB-хаб
                      │ moonraker-ender3 :7127 ↔ klipper-ender3 ─┼─USB─┤  с блоком
                      └──────────────────────────────────────────┘     │  питания
                                                     Ender №1 ◄────────┤
                                                     Ender №2 ◄────────┤
                                                     Ender №3 ◄────────┘
```

Каждый принтер — отдельная пара Klipper + Moonraker со своей папкой
`~/printer_<имя>_data` (конфиги, G-code, логи). Mainsail один, принтеры
переключаются в его меню.

## Ресурсы

Один экземпляр Klipper + Moonraker ≈ 100–200 МБ ОЗУ и немного CPU во время
печати. 8 ГБ ОЗУ хватит с огромным запасом; узким местом будет скорее USB и
стабильность питания, чем процессор. 3–4 принтера на двухъядерном ноутбуке — реально.

## Самое важное: порт каждого принтера

У всех V3 SE одинаковый USB-чип (CH340, `1a86:7523`), поэтому
`/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0` у них **один и тот же** —
Klipper подключится не к тому принтеру. Используем **`/dev/serial/by-path/...`**:
он зависит от физического USB-порта.

```sh
# подключай и включай принтеры по одному
bash find-printers.sh
```

После этого **не переставляй кабели** между портами хаба. Подпиши порты маркером.

## Установка

1. KIAUH: Klipper × N, Moonraker × N, Mainsail × 1 (см. [03-kiauh-install.md](03-kiauh-install.md)).
2. Прошивка: один и тот же `.bin` подходит ко всем принтерам **одной ревизии**
   (при смешанных C13/C14 — собрать отдельно под каждую, если у C14 другой чип).
3. Конфиги:
   ```sh
   bash 04-install-config.sh --instance ender1 --serial /dev/serial/by-path/pci-0000:00:14.0-usb-0:1.1:1.0-port0
   bash 04-install-config.sh --instance ender2 --serial /dev/serial/by-path/pci-0000:00:14.0-usb-0:1.2:1.0-port0
   ```
   PID, Z-offset и сетку стола калибруй **для каждого принтера отдельно** — они
   пишутся в `SAVE_CONFIG` своего `printer.cfg`.
4. Mainsail: открой `http://IP/`, в левом меню «Принтеры» → «+» → адрес
   `IP_ноутбука`, порт `7126` (и т. д.). Первый (7125) Mainsail подхватит сам.
5. Orca: на каждый принтер — свой «физический принтер» со своим портом
   (`IP:7125`, `IP:7126`…), см. [../orca/README.md](../orca/README.md).

## Железо

- **USB-хаб с отдельным блоком питания** (USB 2.0 достаточно). Встроенных
  портов ноутбука обычно 2–3, и при пиковом токе они «проседают».
- Короткие экранированные USB-кабели (до 1,5–2 м), желательно с ферритами.
- Принтеры и ноутбук — от одного удлинителя/сетевого фильтра (общая земля,
  меньше помех по USB).
- Если свет пропадает — ноутбук на батарее переживёт, принтеры — нет; Klipper
  поймает ошибку, печать придётся запускать заново.

## Риски

- Ноутбук завис/перезагрузился → остановились **все** печати. Не ставь на этот
  ноутбук ничего лишнего, обновления делай, когда ничего не печатается.
- `sudo apt upgrade` с перезапуском служб во время печати = сорванная печать.
